# Earlier analyses

The notebooks in [`notebooks/`](notebooks/) and selected analysis helpers in [`scripts/`](scripts/) preserve earlier exploratory and review analyses that may help readers trace method development. They are historical records, not the code used to generate the final manuscript panels. Some contain alternative figures, sample groupings, or methods that were superseded.

For the final publication figures, use [`../publication_notebook/Cheng_TG_RNAseq_publication.qmd`](../publication_notebook/Cheng_TG_RNAseq_publication.qmd) and its [run instructions](../publication_notebook/README.md). The final analysis has pinned inputs and a validated render. Historical notebooks and scripts have not been rerun as part of this release and may require inputs or software versions unavailable in the public deposit.

`7_TG_consensus_identity_refinement.qmd` and `8_TG_final_article_figures.qmd` were recovered from the former private `main` branch. The latter's filename reflects a working stage; it is not the final figure source for the published manuscript. Rendered runs, manuscript drafts, personal paths, private storage manifests, and company assets are excluded from this public archive.

The script archive retains scientific analysis and figure-building helpers from the former private `main` branch. Recipient-specific writing packages, branding utilities, rendered outputs, and private storage records were excluded.
