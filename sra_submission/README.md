# Cheng TG RNA-seq SRA submission tables

`Cheng_TGN_SRA_metadata.tsv` is the 15-library upload table; the XLSX is a review copy based on the supplied NCBI SRA template. The two hDRG comparator libraries each list four FASTQs: paired mates from C1 and C2 technical sequencing runs. The other 13 TGN libraries each list one mate pair, including the pilot W1 library. `sample_name` is the publication-facing identifier used in the processed count matrix.

The FASTQ MD5 manifest is generated by streaming the 34 source objects and verifying byte counts. Each listed filename matched one FASTQ at the root of the dedicated S3 submission bucket. The 34 files were checked by byte count and full-object S3 checksum before the successful NCBI submission. BioProject, BioSample, and SRA accessions are pending and are not recorded in these copies.

`Cheng_TGN_BioSample_Human1.0.tsv` and its XLSX review copy use the same 15 sample names. Known lot and week values distinguish the TGN cultures. The author confirmed that hDRG comparator 2 is a second pooled RNA lot from Takara Bio, Cat# 636150, sequenced twice. The manuscript describes the two lots as derived from normal donors aged 16–65 years. Both comparator rows carry the supplier catalog number, age range, and normal health state. Unknown collection attributes remain `not collected` per the Human 1.0 template. The pooled comparator sex field is `not applicable`, with the pooled source described in the description.
