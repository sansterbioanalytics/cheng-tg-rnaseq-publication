# Cheng TG RNA-seq SRA submission tables

`Cheng_TGN_SRA_metadata.tsv` is the 15-library upload table; the XLSX is a review copy based on the supplied NCBI SRA template. The two hDRG comparator libraries each list four FASTQs: paired mates from C1 and C2 technical sequencing runs. The other 13 TGN libraries each list one mate pair, including the pilot W1 library. `sample_name` is the publication-facing identifier used in the processed count matrix.

The FASTQ MD5 manifest is generated by streaming the 34 source objects and verifying byte counts. Each listed filename must match exactly one object in the flat S3 release-candidate `raw_fastq/` directory before submission. BioProject and BioSample accessions have not been assigned here. The SRA metadata still needs final depositor review, and uploading to SRA requires a separate submission action.

`Cheng_TGN_BioSample_Human1.0.tsv` and its XLSX review copy use the same 15 sample names. Known lot and week values distinguish the TGN cultures. The author confirmed that hDRG comparator 2 is a second pooled RNA sample from the same supplier, sequenced twice. Unknown donor and collection attributes remain `not collected` per the Human 1.0 template. The pooled comparator sex field is `not applicable`, with the pooled source described in the description.
